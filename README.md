# DSA_Java_Python

## Overview

This repository is a hands-on collection of Data Structures and Algorithms examples implemented in Java, Python, C++, and supporting learning scripts. Ideal for students preparing for coding interviews, practice problems, or strengthening DSA fundamentals.

## Repository Structure

- `Array_java/` - Java array problems (problem1.java..problem8.java)
- `Array_Python/` - Python array problems (problem1.py..problem24.py)
- `C++_DSA/` - C++ basics and algorithm examples (arrays, recursion, pointers, loops)
- `Function_python/` - Python function examples (lambda, scope, return, params)
- `List_python/` - Python list practice examples
- `modules/` - Python module/function import examples
- `oops/` - Object-oriented Python examples (classes, inheritance, constructors)
- `Recursion/` - Recursive examples in Python and JavaScript
- `String_python/` - Python string examples
- `Tuple_python/` - Python tuple examples

## Goals

- Learn core DSA topics across languages.
- Compare syntax and algorithm behavior in Java/Python/C++.
- Build confidence with iterative practice problems.

## Getting Started

### Java
1. Open a Java IDE (IntelliJ/Eclipse/VS Code).
2. Compile: `javac Array_java/problem1.java`
3. Run: `java problem1`

### Python
1. `cd` into folder (e.g., `cd Array_Python`).
2. Run: `python problem1.py` (or `python3` depending on setup).

### C++
1. `cd C++_DSA`
2. Build: `g++ array.cpp -o array`
3. Run: `./array`
